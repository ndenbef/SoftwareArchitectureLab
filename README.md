- C# et .NET avancé.
- ASP.NET Core Web API.
- Clean Architecture.
- SOLID et Design Patterns.
- Tests et qualité logicielle.

- Architecture distribuée.
- 
Axe 3 — Infrastructure et Cloud

- CI/CD.
- Azure.
- Sécurité.
- Observabilité.
- 
Axe 4 — Spécialisation métier
